ACTUALIZAR TU WEB

Esta versión permite cargar los tiempos directamente en Organizador → Tiempos:
elegir prueba → lista de nadadores → escribir tiempo → Guardar o Enter.

No hay un orden de salida ni series asignadas en la página.
100.00 se interpreta como un minuto. 32.5 se interpreta como 32.50 segundos.
La pantalla muestra solo los nombres, los campos de tiempo y Guardar.
Borrar un resultado requiere confirmación. Los nadadores sin un registro quedan sin tiempo.

Excel queda únicamente como descarga de inscritos y resultados.
Los grupos del archivo son de tres y sirven solo como referencia para imprimir.
La ruta de importación de Excel se retiró del servidor.

Subí TODOS los cambios al mismo repositorio de GitHub conectado con Vercel.
Incluí el archivo nuevo public/capture.js, package.json y package-lock.json.
Conservá tus variables de Vercel, especialmente MONGODB_DB=TomaDeTiempos.
No borres inscripciones ni tiempos de MongoDB.

RESPALDO
El archivo natacion-base-2026-10-22.zip contiene el código anterior al rediseño.
Conservá ese ZIP; permite volver a la versión previa.
Ver PUNTO-DE-REGRESO.txt. El respaldo de código no revierte datos de MongoDB.
